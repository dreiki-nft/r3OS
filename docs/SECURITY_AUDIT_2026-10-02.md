# Security audit · 2026-10-02

> **Phase 7.6 note (2026-10-04):** this file preserves the 2026-10-02 audit result rather than pretending a later source tree was reviewed that day. Phase 7.5 subsequently renamed fresh-mainnet contracts and added bounded Skrumpeys / Monad Cards holder bonuses. Phase 7.6 then removed discontinued experiments from the fresh-mainnet source/deployment/ABI surface. Those later deltas are covered by their dedicated Foundry/web gates, `THREAT_MODEL.md` and `PRE_MAINNET_CHECKLIST.md`. Existing snapshot-28 testnet bytecode is unchanged.

Original scope on 2026-10-02: the then-current contract suite, web app, scripts, CI, hosting config and dependencies, including experiments that were later removed from the submission branch. Read-only review plus targeted forge PoCs (outside the repo) and browser checks.

**Result: no Critical, High or Medium issue in any contract.** No path was found that steals or locks user MON, lets a session key do more than paint and claim quests, bypasses budgets in a way that matters, or lets the owner exceed the powers listed in `THREAT_MODEL.md`. The web app had one Medium (no CSP / framing protection around a browser-held burner key) and a handful of Lows; all of those are fixed in this change. Contracts were **not** changed (the core stays frozen); their Low findings are listed with a decision for each.

## Fixed in this change (web app, scripts, CI)

| Severity | Finding | Fix |
| --- | --- | --- |
| Medium | No Content-Security-Policy and no framing protection, while the Live-mode burner key sits in `localStorage` and burner paints need no wallet prompt (XSS or clickjacking could drain/abuse it). | `vercel.json` now sends a CSP (`script-src 'self'`, no inline scripts, `object-src 'none'`, `frame-ancestors 'none'`, …), `X-Frame-Options: DENY`, `Cross-Origin-Opener-Policy: same-origin-allow-popups`. Verified: the whole app (paint, Pass, frames, quests, camera, Explore Monad, CD-ROM, sounds, auction) runs with zero CSP violations. |
| Low/Med | A shared link `#/bin?recycle=<id>` opened the irreversible "Confirm recycle" dialog for any frame id, with no id shown. | Recycle requests now travel in memory from My Frames / the desktop Bin only (`src/os/programs/recycleIntent.ts`); a `?recycle=` in a URL is ignored. The confirm text names the frames ("frame #12"). Browser-checked both paths. |
| Low | Quick start / wizard / top-up would send whatever amount an RPC fee quote implied to the burner. | Hard cap `MAX_BURNER_FUND` = 1 MON (`src/live/liveStore.ts`); default funding targets about 20 paints, and Quick Start / wizard / top-up refuse any app funding action that would take the browser-held burner balance above the cap. |
| Low | An expired or revoked Live session kept its leftover MON (and key) with no way to sweep it. | Hardware Profiles: "Sweep leftover MON…" appears when the session is over and the burner has MON; it skips the revoke and sweeps + forgets the key. |
| Low | Launch Doctor echoed unknown flags verbatim, so `--rpc-url=https://…/KEY` printed the key. | Only the flag name is echoed (test added). |
| Low | On-screen errors showed raw viem messages, which include `URL: <rpc>`. | `screenSafeMessage()` (viem short message, URLs replaced by `[rpc]`) is used by `errorText()`, DXDIAG and every program's error display. |
| Low | `#/auction?token=abc` crashed the Auction window (`BigInt('abc')`); other route params fed `NaN` / free text into the UI (frame-properties title bar). | Integer-only route parsing (`src/lib/route.ts`, `routeNumber`), title bar shows digits only. |
| Low | CI: default token permissions, actions pinned by tag, `npm install` drifting from the lockfile. | `permissions: contents: read`, actions pinned to commit SHAs, `persist-credentials: false`, `npm ci`. |
| Low | `npm audit`: 1 High in `tmp` via the unused `solc` dev dependency. | `solc` removed; `npm audit` now reports 0. |
| Low | `.gitignore` missed `.env.*` variants, keystores, password files, Launch Doctor JSON. | Added. |

Checked and fine in the app: no `dangerouslySetInnerHTML`/`innerHTML`/`eval`; onchain SVG/JSON only ever rendered through `<img>`; all `target=_blank` links have `rel=noreferrer`; Run… is a strict allow-list; the session EIP-712 domain matches the contract; the burner key never leaves the browser; only `VITE_WALLET_RPC_URL` reaches the wallet; DXDIAG's report is redacted; production dependencies have no advisories.
